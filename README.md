# 随机点名 · 课堂互动

一个面向中小学课堂的**随机点名**网页应用。单文件、零依赖、可离线运行，支持多班级管理与离线 HTML 导出。

> 在线使用：部署到 Cloudflare Pages 后，打开网址 → 选择班级 → 开始点名。

---

## 功能

| 功能 | 说明 |
|---|---|
| 随机点名 | 密码学安全随机数（`crypto.getRandomValues`），支持一次抽取 1–12 人 |
| 动画效果 | 名字高速滚动 → 缓动减速 → 揭晓弹跳 + 彩带粒子 + 音效 |
| 不重复抽取 | 自动排除本轮已点到的学生，剩余人数实时显示 |
| 多班级 | 下拉切换班级，每个班独立名单与点名记录 |
| 管理后台 | 增删改班级、可视化编辑学生名单、去重整理、JSON 导入导出 |
| 离线导出 | 一键把所有班级打包成单个 HTML，双击即用，可存 U 盘，无需联网 |
| 全屏投影 | 右上角全屏按钮，适合教室大屏 |
| 响应式 | 桌面 / 平板 / 手机自适应 |

### 快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 开始点名 |
| `F` | 全屏切换 |
| `Esc` | 关闭弹窗 |

## 部署到 Cloudflare Pages

### 方式一：连接 GitHub 仓库（推荐，可自动更新）

1. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 授权 GitHub，选择仓库 `666mingqing6/901`
3. 构建设置保持默认：
   - **Framework preset**：`None`
   - **Build command**：留空
   - **Build output directory**：`/`（或留空）
4. 点击 **Save and Deploy**，约 30 秒后获得 `https://<项目名>.pages.dev` 网址

之后每次向仓库 `main` 分支推送，Cloudflare 会自动重新部署。

### 方式二：直接上传（不用 Git）

在 Pages 页面选择 **Upload assets**，把本目录下的 `index.html` 拖进去即可。

## 使用说明

### 1. 点名

- 顶部下拉选择班级 → 点击「开始点名」或按空格
- 「抽取人数」可设置一次抽几人（1–12）
- 开启「不重复」后，已点到的学生不会再次出现；抽完时点「重置」清空记录

### 2. 管理后台（右上角「管理」）

- **班级管理**：新增 / 重命名 / 删除班级，点击卡片切换当前班级
- **学生名单**：每行一个姓名，也支持用「、，, 空格 制表符」分隔，保存时自动拆分去重
- **导出 / 备份**：
  - 「下载离线 HTML」→ 生成单文件版本，含全部班级数据
  - 「导出 JSON / 导入 JSON」→ 跨设备迁移数据
- **设置**：音效开关、管理员密码（可选）

### 3. 离线版（U 盘使用）

在「管理 → 导出」下载 `随机点名_日期.html`，拷到 U 盘或任意电脑，**双击即可打开使用，完全不需要联网**。

> 注意：离线版中修改名单后，需要重新导出一次才会保存（浏览器对本地文件的数据存储限制）。在线版则自动保存到浏览器本地。

---

## 数据存储

- **在线版**：班级与名单保存在浏览器 `localStorage`（键名 `rollcall.v2`），换浏览器或清缓存会丢失，建议定期「导出 JSON」备份。
- **离线版**：数据内嵌在 HTML 文件中，不依赖浏览器存储。
- 点名记录仅保存在当前会话内存中，刷新页面即清空。

---

## 技术说明

- 纯静态：HTML + CSS + 原生 JavaScript，**无任何第三方库、无 CDN 依赖**
- 单文件约 40 KB，首屏无外部请求，离线可用
- 音效使用 Web Audio API 实时合成，无音频文件
- 彩带使用 Canvas 2D 绘制
- 图标为内联 SVG data URI
