# 随机点名 · 课堂互动

一个面向中小学课堂的**随机点名**网页应用。单文件、零依赖、可离线运行，支持多班级管理与离线 HTML 导出。

> 在线使用：部署到 Cloudflare Pages 后，打开网址 → 选择班级 → 开始点名。

---

## 功能

| 功能 | 说明 |
|---|---|
| 随机点名 | Web Crypto CSPRNG（系统熵池）+ 拒绝采样 + Fisher–Yates 洗牌，**数学上严格等概率**，支持一次抽 1–12 人 |
| 动画效果 | 名字高速滚动 → 缓动减速 → 揭晓弹跳 + 彩带粒子 + 音效 |
| 自动播报 | 点到名字后自动用系统中文语音朗读（Web Speech API，无需联网、无需音频文件），主界面一键开关 |
| 不重复抽取 | 自动排除本轮已点到的学生，剩余人数实时显示 |
| 多班级 | 下拉切换班级，每个班独立名单与点名记录 |
| 管理后台 | 增删改班级、可视化编辑学生名单、去重整理、JSON 导入导出 |
| 离线导出 | 一键把所有班级打包成单个 HTML，双击即用，可存 U 盘，无需联网 |
| 全屏投影 | 右上角全屏按钮，适合教室大屏 |
| 深浅主题 | 明亮暖白（默认）/ 深色墨蓝，顶栏一键切换，配置随导出打包 |
| 响应式 | 桌面 / 平板 / 手机自适应 |

## 部署到 Cloudflare Pages

### 方式一：连接 GitHub 仓库（推荐，可自动更新）

1. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 授权 GitHub，选择仓库 `666mingqing6/901`
3. 构建设置保持默认：
   - **Framework preset**：`None`
   - **Build command**：留空
   - **Build output directory**：`/`（或留空）
4. 点击 **Save and Deploy**，约 30 秒后获得 `https://<项目名>.pages.dev` 网址

之后每次向仓库 `main` 分支推送，Cloudflare 会自动重新部署。

### 方式二：直接上传（不用 Git）

在 Pages 页面选择 **Upload assets**，把本目录下的 `index.html` 拖进去即可。

## 使用说明

### 1. 点名

- 顶部下拉选择班级 → 点击「开始点名」或按空格
- 「抽取人数」可设置一次抽几人（1–12）
- 开启「不重复」后，已点到的学生不会再次出现；抽完时点「重置」清空记录

### 1.1 自动播报

底部控制栏的「自动播报」按钮控制语音朗读，默认开启：

- **开启**（按钮高亮）：每次揭晓后用系统中文语音念出学生姓名；多人时读作「张三、李四、王五」
- **关闭**（按钮变灰）：只显示名字，不出声
- 揭晓瞬间即开口，**无额外延时**：程序在滚动动画期间会预热语音引擎，避免首次调用时的启动卡顿
- 浏览器没有可用语音时按钮会自动禁用并提示
- 语音来自操作系统自带的 TTS（Windows 为「Microsoft Huihui / Xiaoxiao」等），**不联网、不调用云端接口**

> 若觉得播报音色不理想，可在系统「设置 → 时间和语言 → 语音」中安装/切换中文语音包。

### 1.2 随机性说明

点名使用的是浏览器**最强可用的随机源**：

1. **`crypto.getRandomValues()`** —— 密码学安全伪随机数发生器（CSPRNG），
   由操作系统熵池（Windows 为 `BCryptGenRandom`）播种，与生成加密密钥同源。
   它**不是** `Math.random()` 那种可预测的快速 PRNG。
2. **拒绝采样** —— 直接对 2³² 取模会让前几个数概率略高（取模偏差），
   本实现丢弃尾部无法整除的区间，保证 `[0, n)` 上每个值概率严格相等。
3. **部分 Fisher–Yates** —— 第 i 轮从剩余学生中均匀取一个换到第 i 位，
   不存在"名单靠前/靠后更容易被点"的位置偏好。

需要说明的客观限制：浏览器没有暴露硬件真随机源（如 `/dev/random` 的物理噪声），
因此**任何网页都做不到物理意义上的"真随机"**。上述方案是网页端能达到的最高标准，
与银行、加密通信使用的是同一级别的随机源。

**可自行验证**：管理 → 设置 → 「运行自检」。程序会用当前班级名单模拟约 11 万次抽取，
统计每名学生被点中的次数，并用卡方检验判断分布是否均匀。正常结果形如：

```
分布均匀   抽样 110,000 次 · 55 人
理论概率 1.82%（1/55）  实际 1.74% ~ 1.90%
χ² = 51.8（df=54，p ≈ 0.56）
```

`p > 0.05` 即表示差异属于正常随机波动。多次运行 p 值会在 0.1~0.9 之间跳动，
这正是真随机应有的表现。

### 2. 管理后台（右上角「管理」）

- **班级管理**：新增 / 重命名 / 删除班级，点击卡片切换当前班级
- **学生名单**：每行一个姓名，也支持用「、，, 空格 制表符」分隔，保存时自动拆分去重
- **导出 / 备份**：
  - 「下载离线 HTML」→ 生成单文件版本，含全部班级数据
  - 「导出 JSON / 导入 JSON」→ 跨设备迁移数据
- **设置**：音效开关、管理员密码（可选）

### 3. 离线版（U 盘使用）

在「管理 → 导出」下载 `随机点名_日期.html`，拷到 U 盘或任意电脑，**双击即可打开使用，完全不需要联网**。

> 注意：离线版中修改名单后，需要重新导出一次才会保存（浏览器对本地文件的数据存储限制）。在线版则自动保存到浏览器本地。

## 数据存储

- **在线版**：班级与名单保存在浏览器 `localStorage`（键名 `rollcall.v2`），换浏览器或清缓存会丢失，建议定期「导出 JSON」备份。
- **离线版**：数据内嵌在 HTML 文件中，不依赖浏览器存储。
- 点名记录仅保存在当前会话内存中，刷新页面即清空。

---

## 技术说明

- 纯静态：HTML + CSS + 原生 JavaScript，**无任何第三方库、无 CDN 依赖**
- 单文件约 40 KB，首屏无外部请求，离线可用
- 音效使用 Web Audio API 实时合成，无音频文件
- 语音播报使用浏览器内置 Web Speech API（`speechSynthesis`），调用系统 TTS，不依赖任何在线服务
- 深浅主题通过 CSS 变量 + `data-theme` 属性切换，同一份样式表内完成，不额外加载资源
- 彩带使用 Canvas 2D 绘制
- 图标为内联 SVG data URI
